# 启动说明

此文件夹是 2026-10-24 整理的项目副本，包含后端源码、网页、测试文件、文档和审查历史数据库。

## 在电脑上启动

1. 安装 Python 3.12（本机已安装）。
2. 双击本文件夹中的 `start.cmd`。
3. 首次启动会创建 `.venv` 并联网安装依赖，随后自动打开浏览器。
4. 保持启动窗口开启；关闭窗口会停止服务。地址以启动窗口显示为准。

如果已有旧版服务运行，启动脚本可能打开已有服务。要运行此副本，请先关闭旧版服务的启动窗口，再双击此处的 `start.cmd`。

## 使用 PyCharm

用 PyCharm 打开此文件夹。首次运行 `start.cmd` 后，将项目解释器设为本文件夹下的 `.venv\Scripts\python.exe`。

## 大模型与数据

Codex 本机模式仍需在使用的电脑上安装并登录 Codex。此文件夹不包含 Codex 账号登录凭据。静态分析与基础知识图谱可独立于大模型使用。

`data\review_history.sqlite3` 是打包时的审查历史备份。后续在原项目产生的新记录不会自动同步到此副本。

此包不附带 Python 运行时或已安装的虚拟环境；换电脑使用时须先安装 Python，并在首次启动时联网安装依赖。
