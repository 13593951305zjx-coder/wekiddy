## 本轮已实现

- 分析结果增加风险等级筛选、规则/问题/文件搜索，支持组合筛选。
- 显示匹配数量与总数量，提供无匹配提示。
- 筛选改变所选问题时同步更新详情，清理旧修复预览；清空搜索后恢复可见问题的详情。
- 窄屏收起侧栏中的累计项目统计，减少到达代码编辑器前的滚动距离。
- 更新前端资源版本，避免浏览器继续使用旧缓存。

筛选只改变当前列表展示，不改变完整分析结果及导出报告。
